# Changelog

## 1.0.0 — 2026-10-23

First public source release of the university organizer dashboard and customization overlay for PC² 9.10.0 / WTI 1.1.

- Contest preparation/lifecycle, problem resources, difficulty and balloon colors.
- Role-based organizer workflows, optional TOTP and approved HTTPS remote access.
- Automatic, human-only and automatic-plus-human judgement workflows.
- Participant identity, clocks, precise verdicts, diagnostics and retained notifications.
- Private live/public frozen standings, reports and encrypted backup integration.
- Post-contest per-team learning archives with current-data isolated replay.
- Searchable in-dashboard User Guide, About, original developer credits and university context.
- Open-source attribution, contribution/security policies and explicit deployment limitations.

This version does not certify a fresh installation on every host or full parity with every native PC² deployment. See [roadmap](docs/ROADMAP.md).
